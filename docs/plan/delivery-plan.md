# Delivery plan: Sprint 0 to version 1.0

Two-week sprints, four teams (about 18 people). Every sprint starts from a detailed specification and ends with green CI and a merged pull request.

Change log: DealIQ upgrade added to Team D (+3 sprints of work), version 1.0 moved from Sprint 61 to Sprint 63 (committed 65 to 67).

## Milestones

| Sprint             | Milestone                                                                                                                                          |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0                  | Foundation: repository, CI, architecture, plan, Platform Core specification                                                                        |
| 8                  | Platform Core usable internally: tenancy, identity, roles, audit, domains                                                                          |
| 26                 | Pilot: existing RightAlly customers start moving across (back office first)                                                                        |
| 26, 32, 39, 46, 52 | Quarterly release waves to existing customers, suite by suite                                                                                      |
| 56-63              | All teams: integration, full regression, 1-million-agent load test, penetration test, SOC 2 readiness, migration of all existing customers, launch |
| 63                 | Version 1.0 general availability                                                                                                                   |
| 67                 | Committed date including a 4-sprint buffer                                                                                                         |

## Five-team alternative

A fifth team (about 4 people) takes the growth modules: solo plan, referral and affiliate programme, Brokerage Health Check and branded preview, Lead Generation Engine, Recruiting Attraction Engine and solo website templates. Teams A to D then finish their remaining items earlier, bringing version 1.0 to about Sprint 55 (committed Sprint 59). Decide before Sprint 1.

## Rules

- The scope is locked; additions go through a change request showing their effect on this plan.
- Each sprint's specification is written and reviewed before the sprint starts.
- A sprint is done only when CI is green and the pull request is merged.
- This plan is re-estimated after Sprint 5 using measured velocity.

# Easy to use: product principles (all modules)

Brokers and agents only use what is easy. Every module must pass these principles; they are part of
the definition of ready (in the spec) and the definition of done (tested with real users).

| Principle                 | In practice                                                                                                                        |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Works on first use        | No required setup or templates; first useful result in under 5 minutes (e.g. one contract → a complete deal in under 2 minutes)    |
| One place, one box        | One screen per record and one "Ask anything or tell me what to do" box with a mic; users never need to know which module does what |
| Talk like a person        | Plain English and Spanish, no jargon; every AI action previewed in one sentence with a single **Confirm**                          |
| Do it for me              | Sensible defaults for reminders, schedules and checklists; settings optional, never required to start                              |
| Three taps                | The ten most common actions in each module take no more than three taps on a phone                                                 |
| What matters today first  | Screens open on "What needs you today"; everything else one tap away                                                               |
| Teach in the moment       | A sample record to try on first login, short tips the first time a feature appears, no training course needed                      |
| Branded, never plain      | Every AI message, video and document uses the brokerage's Brand Kit and Brand Voice and passes the brand check                     |
| Brokers set up in minutes | The AI setup assistant proposes settings from the brokerage's state and size; the broker reviews and approves                      |

## How we check it

- **Usability test every sprint that ships screens:** five real agents or brokers, 30 minutes each,
  on the actual build; anything they struggle with is fixed before release.
- **Measures:** time to first useful result (target under 5 minutes), share of invited agents active
  in their first week, share still active weekly after a month.
- **Pilot:** existing RightAlly customers' agents are the first testers.

## RightAlly AI Transaction Suite

DocIQ (the document brain) and Deal-IQ (the AI transaction coordinator) are sold together as the
**RightAlly AI Transaction Suite**; DocIQ alone remains the entry option. Agents see one assistant
on each deal; the module names are for brokers and packaging.

# ADR 0004: MySQL 8.4 LTS for data, OpenSearch for search

Status: **Accepted**

## Context

Relational money and workflow data need transactions and foreign keys; listing search needs geo and faceting across millions of records.

## Decision

MySQL 8.4 LTS (Aurora) per cell with read replicas; OpenSearch for listings (one index per region, fed once per MLS) and CRM/document search.

## Alternatives considered

- PostgreSQL: viable, but team expertise and legacy data are MySQL.
- MySQL-only search: cannot meet the < 300 ms listing search target at scale.

## Consequences

- Analytics move to a warehouse (ClickHouse or Redshift) so reports never load the primary.

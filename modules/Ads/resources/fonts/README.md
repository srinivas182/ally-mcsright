# Ally Studio fonts

Latin subsets (WOFF2) bundled so Studio designs render the same on every render worker, without calling a font
service. All are licensed under the SIL Open Font License 1.1 (see `OFL-LICENSE.txt`), from the Fontsource
packages: Playfair Display, Cormorant Garamond, Libre Baskerville, DM Serif Display, Inter, Montserrat, DM Sans,
Lato.
